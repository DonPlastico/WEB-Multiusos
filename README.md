# WEB Multiusos (DP-SYS)

[![Netlify Status](https://api.netlify.com/api/v1/badges/d2c14ea5-2f01-4c05-a5b4-193b69d4c25d/deploy-status)](https://app.netlify.com/projects/dpsys-nexus/deploys)

## 🚀 Sobre la web

Centro de control para juegos, películas y series. Con APIs de IGDB, TMDB, ITAD y Supabase.

## 🛠️ Tecnologías

- HTML5, CSS3, JavaScript
- Netlify Functions
- Supabase (autenticación y BD)
- APIs: IGDB, TMDB, ITAD, Twitch

## 📦 Instalación local

```bash
npm install
npm run dev
```

## 🌐 Web en producción

https://dpsys-nexus.netlify.app

## 📋 **Resumen y orden de instalación**

| Paso | Herramienta           | ¿Qué hacer?                          |
| ---- | --------------------- | ------------------------------------ |
| 1️⃣   | **Lighthouse Plugin** | Instálalo desde la sección Deploys   |
| 2️⃣   | **SEO Plugin**        | Instálalo desde Extensions           |
| 3️⃣   | **CSP Generator**     | Instálalo desde Extensions           |
| 4️⃣   | **Cypress**           | Instálalo desde Extensions (o local) |
| 5️⃣   | **Deploy Badge**      | Copia el código y ponlo en README.md |

---

## ⚠️ **Importante**

- **Instala los plugins UNO POR UNO** para asegurarte de que ninguno rompa tu web
- **Después de cada instalación**, espera al deploy y prueba que la web siga funcionando
- **Si algo falla**, desinstala el plugin y avísame
